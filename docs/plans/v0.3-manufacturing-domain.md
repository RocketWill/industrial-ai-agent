# v0.3 Manufacturing Domain — Implementation Plan

**Status: In Progress**

This plan implements the approved PRD through independently verifiable
vertical slices. It does not authorize API, LangGraph, database, or UI
integration.

## Slice 1 — Shared language

**Status: Implemented**

- Define canonical domain terms in `CONTEXT.md`.
- Keep observations, calculations, and interpretation distinct.
- Verify the glossary against the PRD and public-safety boundary.

## Slice 2 — Time and inspection invariants

**Status: Implemented**

- Add the manufacturing domain module under
  `apps/api/src/industrial_agent/domain/`.
- Add immutable Time Range and Inspection Record types.
- Test UTC-only half-open ranges, non-negative counts, count conservation, and
  Defect Count limits through public constructors.
- Verify with `uv run pytest tests/domain/test_manufacturing.py -q`.

## Slice 3 — Deterministic Production Summary

**Status: Implemented**

- Add Equipment, Production Lot, Defect Count, Alarm Event, and Production
  Summary types.
- Add `summarize_production()` as the public calculation seam.
- Test Equipment and Time Range filtering, Yield Rate, deterministic defect
  aggregation, overlapping alarms, and explicit empty results.
- Exclude causal inference and model-generated interpretation.

## Slice 4 — Reproducible AOI scenario

**Status: Implemented**

- Store the independently authored dataset at
  `data/synthetic/aoi-wafer-inspection-v1.json`.
- Load it through validated public domain types.
- Test identity, time coverage, wafer unit, fictional alarm, and absent causal
  claim.

## Slice 5 — Remaining v0.3 semantics

**Status: Planned**

- Decide Equipment Status semantics before adding a model or calculation.
- Decide whether throughput is part of v0.3 or v0.4.
- Add tests first for each approved behavior.
- Update the PRD, roadmap, scope, and implementation status from verified
  results.

## Milestone verification

Run from `apps/api`:

```bash
uv run pytest -q
uv run ruff check .
uv build
```

Run from the repository root:

```bash
python -m json.tool data/synthetic/aoi-wafer-inspection-v1.json >/dev/null
git diff --check
git status --short
```

Do not mark v0.3 Implemented until its remaining semantics are either completed
or explicitly removed from the approved milestone boundary.
