# Web

## Purpose

This directory will contain the React and TypeScript frontend for v0.1.

## Planned v0.1 responsibilities

- create and reopen conversations;
- display persisted message history;
- send user messages and display assistant responses; and
- present backend and configuration failures clearly.

## Non-responsibilities

Agent traces, tool timelines, RAG sources, manufacturing charts,
authentication, and administrative interfaces are outside v0.1.

## Dependency management

The frontend will use npm with `package.json` and a committed lockfile in this
directory. Vite and test dependencies will be added only when the executable
frontend is created.

## Current status

**Planned** — no frontend code or dependencies exist yet.
